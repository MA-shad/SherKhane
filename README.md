# شعرخونه (SherKhaneh) 🪶

پلتفرم وب تعاملی، زنده و مدرن برای تجربهٔ روزمرهٔ ادبیات، مطالعهٔ دیوان‌ها، حفظ شعر و تالار مشاعرهٔ پارسی.

---

## ۱. ساختار جامع مخزن و بخش‌های توسعه‌یافته

این مخزن شامل سه بخش اصلی و تفکیک‌شده است:

```text
SherKhane/
├── backend/                  # کدهای بک‌اند اولیه مالک پروژه (دست‌نخورده و مستقل)
│   ├── accounts/             # اپلیکیشن اولیه حساب کاربری
│   ├── divan/                # اپلیکیشن اولیه اشعار
│   └── config/               # تنظیمات اولیه پروژه
│
├── vibe-coding/              # پیاده‌سازی کامل صفر تا صد (Production-Grade Codebase)
│   ├── backend/              # بک‌اند ماژولار جنگو و DRF
│   │   ├── accounts/         # مدیریت پیشرفته کاربران، XP، روزهای متوالی و نشان‌ها
│   │   ├── core/             # نرمال‌ساز متن و املای فارسی و تطبیق حروف
│   │   ├── poetry/           # گنجینه اشعار، اوزان عروضی، قالب‌ها و کاتالوگ دیوان
│   │   ├── library/          # دفترچه شخصی، علاقه‌مندی‌ها و یادداشت‌ها
│   │   ├── memorization/     # استودیو حفظ شعر با متد لایتنر و تکرار با فاصله (SM-2)
│   │   ├── mushaereh/        # تالار مشاعره زنده با داوری مقتدرانه سرور و ربات سخن‌سنج
│   │   ├── games/            # ۴ بازی ادبی (بیت‌چین، حدس شاعر، تکمیل مصراع، واژه‌نامه)
│   │   ├── daily_content/    # فال حافظ با تعبیر معنوی، بیت روز و ضرب‌المثل روز
│   │   └── tests/            # مجموعه ۱۶ آزمون خودکار واحد و یکپارچگی (۱۰۰٪ قبولی)
│   ├── frontend/             # وب‌اپلیکیشن تعاملی و واکنش‌گرا با پالت زرین و فونت فارسی
│   │   ├── index.html        # واسط کاربری یکپارچه و مدرن
│   │   ├── css/style.css     # سیستم طراحی فاخر و راست‌چین (RTL)
│   │   └── js/               # کلاینت ای‌پی‌آی و منطق تعاملی بازی‌ها و مشاعره
│   ├── run_backend.bat       # اجرای تک‌کلیکی سرور جنگو
│   └── run_frontend.bat      # اجرای تک‌کلیکی فرانت‌اند
│
├── docs/                     # مستندات بیست‌گانه تفصیلی معماری و ممیزی سیستم
└── SHERKHANEH_MASTER_BLUEPRINT.md # سند طرح جامع یکپارچه جهت ارزیابی و بازخورد
```

## ۲. اسناد و طرح جامع معماری

- 📄 **[سند طرح جامع معماری (Master Blueprint)](./SHERKHANEH_MASTER_BLUEPRINT.md):**  
  سند یکپارچه شامل ممیزی فنی، ساختار دیتابیس، مدل‌های داده، موتور نرمال‌ساز متن فارسی، الگوریتم حفظ شعر با تکرار با فاصله (SM-2)، سیستم داوری مشاعره و راهنمای ارزیابی برای ChatGPT.
- 📁 **[پوشه مستندات تفصیلی (Architecture Blueprint Docs)](./docs/):**  
  شامل ۲۰ سند تخصصی مجزا از قبیل ای‌آردی دیتابیس، دیکشنری داده‌ها، مشخصات OpenAPI، راهبرد آزمون‌ها و برنامهٔ ۵ تا ۶ ماهه.
- 💻 **[کدهای پیاده‌سازی کامل صفر تا صد](./vibe-coding/):**  
  تمامی کدهای عملیاتی فرانت‌اند و بک‌اند با قابلیت اجرای مستقل.

## ۳. راهنمای ارزیابی و بررسی برای هوش مصنوعی و تحلیل‌گران (ChatGPT Review Guide)

اگر به عنوان تحلیل‌گر یا مدل هوش مصنوعی (مانند ChatGPT) این مخزن را بررسی می‌کنید، می‌توانید کدهای کامل پیاده‌سازی‌شده را در مسیرهای زیر بخوانید:

- **الگوریتم نرمال‌سازی متن فارسی:** [`vibe-coding/backend/core/normalizer.py`](./vibe-coding/backend/core/normalizer.py)
- **موتور تکرار با فاصله (SM-2) حفظ شعر:** [`vibe-coding/backend/memorization/services.py`](./vibe-coding/backend/memorization/services.py)
- **داوری مقتدرانه سرور و ضدتقلب مشاعره:** [`vibe-coding/backend/mushaereh/services.py`](./vibe-coding/backend/mushaereh/services.py)
- **مدل‌های داده‌ای گنجینه دیوان:** [`vibe-coding/backend/poetry/models.py`](./vibe-coding/backend/poetry/models.py)
- **آزمون‌های خودکار سیستم:** [`vibe-coding/backend/tests/`](./vibe-coding/backend/tests/)
- **رابط کاربری و سیستم طراحی:** [`vibe-coding/frontend/index.html`](./vibe-coding/frontend/index.html) و [`vibe-coding/frontend/css/style.css`](./vibe-coding/frontend/css/style.css)
