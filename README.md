# شعرخونه (SherKhaneh) 🪶

پلتفرم وب تعاملی، زنده و مدرن برای تجربهٔ روزمرهٔ ادبیات، مطالعهٔ دیوان‌ها، حفظ شعر و تالار مشاعرهٔ پارسی.

---

## اسناد و طرح جامع معماری

طرح جامع معماری، ممیزی وضعیت موجود، مدل‌های داده و نقشهٔ راه این پروژه در اسناد زیر تدوین شده است:

- 📄 **[سند طرح جامع معماری (Master Blueprint)](./SHERKHANEH_MASTER_BLUEPRINT.md):**  
  سند یکپارچه شامل ممیزی فنی، ساختار دیتابیس، مدل‌های داده، موتور نرمال‌ساز متن فارسی، الگوریتم حفظ شعر با تکرار با فاصله (SM-2)، سیستم داوری مشاعره و راهنمای ارزیابی برای ChatGPT.
- 📁 **[پوشه مستندات تفصیلی (Architecture Blueprint Docs)](./docs/):**  
  شامل ۲۰ سند تخصصی مجزا از قبیل ای‌آردی دیتابیس، دیکشنری داده‌ها، مشخصات OpenAPI، راهبرد آزمون‌ها و برنامهٔ ۵ تا ۶ ماهه.

---

## ساختار پوشه‌های مخزن

```text
SherKhane/
├── backend/                  # بک‌اند پروژه با جنگو و جنگو رست
│   ├── accounts/             # اپلیکیشن مدیریت کاربران و احراز هویت
│   ├── divan/                # اپلیکیشن اولیه کاتالوگ دیوان
│   └── config/               # تنظیمات اصلی پروژه
├── docs/                     # مستندات بیست‌گانه معماری و ممیزی سیستم
├── SHERKHANEH_MASTER_BLUEPRINT.md # طرح جامع یکپارچه جهت ارزیابی و بازخورد
├── requirements.txt
└── .env.example
```

---

## راه‌اندازی سریع در محیط توسعه

۱. فعال‌سازی محیط مجازی:
```bash
.venv\Scripts\activate
```

۲. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

۳. اجرای سرور توسعه:
```bash
python backend/manage.py runserver
```
