# فرهنگ جامع داده‌ها و دیکشنری مدل‌ها (Data Dictionary)

این سند، تعاریف جداول، فیلدها، انواع داده، قیدهای یکتایی و ایندکس‌های پایگاه داده را تشریح می‌نماید.

---

## ۱. جدول شاعران (`poetry_poet`)

| نام فیلد | نوع داده | وضعیت خالی | قیدها و ایندکس | شرح فیلد |
| :--- | :--- | :---: | :--- | :--- |
| `id` | BigAutoField | خیر | کلید اصلی | شناسه عددی یکتای شاعر |
| `name` | CharField(150) | خیر | Index | نام کامل شاعر (مثلاً: سعدی شیرازی) |
| `slug` | SlugField(150) | خیر | Unique | شناسه متنی برای آدرس‌دهی تمیز |
| `bio` | TextField | بله | - | شرح زندگانی، سبک و جایگاه ادبی |
| `century` | SmallIntegerField | بله | Index | سده زندگی به هجری قمری |
| `avatar` | ImageField / URL | بله | - | نگاره یا تذهیب نمایانگر شاعر |

| نام فیلد | نوع داده | وضعیت خالی | قیدها و ایندکس | شرح فیلد |
| :--- | :--- | :---: | :--- | :--- |

## ۶. جدول یادسپاری و حفظ شعر (`memorization_record`)

| نام فیلد | نوع داده | وضعیت خالی | قیدها و ایندکس | شرح فیلد |
| :--- | :--- | :---: | :--- | :--- |
| `id` | BigAutoField | خیر | کلید اصلی | شناسه رکورد یادسپاری |
| `user_id` | ForeignKey | خیر | Unique Together | شناسه کاربر |
| `poem_id` | ForeignKey | خیر | Unique Together | شناسه شعر در حال حفظ |
| `mastery_level`| SmallInt | خیر | - | سطح تسلط (۰: نو، ۱: در حال یادگیری، ۲: مسلط) |
| `easiness_factor`| FloatField | خیر | - | ضریب آسانی بر پایه الگوریتم لایتنر/سوپرممو |
| `interval_days` | IntegerField | خیر | - | فاصله روزها تا مرور بعدی |
| `next_review_date`| DateField | خیر | Index | تاریخ زمان‌بندی‌شده برای مرور بعدی |
| `repetition_count`| IntegerField| خیر | - | تعداد دفعات تکرار موفق |
| `last_reviewed_at`| DateTime | بله | - | تاریخ و ساعت آخرین جلسه آزمون |
