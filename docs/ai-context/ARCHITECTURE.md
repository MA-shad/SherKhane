# معماری فنی پروژه شعرخانه (SherKhane)

## ۱. پشته فناوری (Technology Stack)
- **زبان**: پایتون ۳.۱۲+
- **فریم‌ورک وب**: Django 5.x + Django REST Framework (DRF)
- **پایگاه داده**: PostgreSQL (محیط توسعه لوکال / داکر)
- **احراز هویت**: JWT (JSON Web Tokens) با پکیج `djangorestframework-simplejwt`
- **کانفیگ محیطی**: `python-dotenv` و فایل `.env`
- **کانتینرسازی و استقرار**: Docker & Docker Compose (در حال استانداردسازی)

## ۲. ساختار اپلیکیشن‌های بک‌اند (`backend/`)
- `config/`: تنظیمات اصلی پروژه، پیکربندی CORS، تنظیمات JWT و اتصال دیتابیس.
- `accounts/`:
  - مدیریت مدل‌های کاربری و احراز هویت.
  - ثبت‌نام، ورود، دریافت و تازه‌سازی توکن‌های JWT.
- `divan/`:
  - هسته داده‌های ادبی و شعری.
  - مدل‌های اصلی: `Poet` (شاعر)، `Poem` (شعر)، `Verse` (بیت)، `Rhythm` (وزن عروضی).
  - استفاده از `DefaultRouter` و `ModelViewSet` برای ارائه اندپوینت‌های استاندارد REST.

## ۳. نگاشت مدل‌های داده (`backend/divan/models.py`)
- **Poet**: نام شاعر، بیوگرافی، دوره تاریخی، تصویر.
- **Rhythm**: نام وزن عروضی، تقطیع، بحر عروضی.
- **Poem**: عنوان شعر، ارتباط با شاعر (ForeignKey)، ارتباط با وزن (ForeignKey)، فیلد `created_at` (تاریخ ثبت).
- **Verse**: متن مصرع اول و دوم، شماره ترتیب بیت در شعر، ارتباط با شعر (ForeignKey).
