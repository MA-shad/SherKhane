# راهنمای مستندات حافظه هوش مصنوعی — پروژه شعرخانه (SherKhane)

این پوشه شامل مستندات ساختاریافته از پیشینه، معماری، تصمیمات فنی و وضعیت توسعه پروژه «شعرخانه» است. این اسناد به Agent هوش مصنوعی در Antigravity IDE کمک می‌کنند تا بدون نیاز به توضیحات تکراری، با همان عمق و شناخت قبلی به همکاری ادامه دهد.

## ترتیب مطالعه برای Agent
1. [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md): معرفی اهداف، فلسفه محصول و محدوده پروژه.
2. [ARCHITECTURE.md](./ARCHITECTURE.md): معماری فنی بک‌اند، ساختار اپلیکیشن‌ها و دیتابیس.
3. [DEVELOPMENT_STATUS.md](./DEVELOPMENT_STATUS.md): تفکیک دقیق امکانات پیاده‌شده، در حال ساخت و ایده‌های آینده.
4. [DECISIONS.md](./DECISIONS.md): تصمیمات فنی ثبت‌شده و اصلاحات بحرانی پیشین.
5. [LEARNING_CONTEXT.md](./LEARNING_CONTEXT.md): سطح یادگیری، مباحث آموزش‌داده‌شده و سبک همکاری آموزشی.
6. [CONVERSATION_INDEX.md](./CONVERSATION_INDEX.md): فهرست مکالمات تاریخی مرتبط در Antigravity.
7. [OPEN_QUESTIONS.md](./OPEN_QUESTIONS.md): چالش‌های باز و موضوعات نیازمند بررسی.
