# معرفی و چشم‌انداز پروژه شعرخانه (SherKhane)

## ۱. هویت و ماهیت پروژه
پروژه «شعرخانه» یک وب‌اپلیکیشن جامع برای ثبت، جستجو، تعامل و بازی‌های ادبی با محوریت شعر فارسی است. این پروژه یک پروژه عملی-آموزشی هنرستان (رشته شبکه و نرم‌افزار، پایه یازدهم) است که با استانداردهای مهندسی نرم‌افزار و معماری مقیاس‌پذیر در حال پیاده‌سازی است.

## ۲. تیم و نقش‌ها
- **توسعه‌دهنده بک‌اند (کاربر)**: طراحی دیتابیس، زیرساخت داکر، APIهای REST با فریم‌ورک جنگو و DRF، سیستم احراز هویت و مدیریت داده‌ها.
- **توسعه‌دهنده فرانت‌اند (هم‌کلاسی)**: پیاده‌سازی رابط کاربری مدرن با React و Tailwind CSS.

## ۳. اهداف کلیدی محصول
- ایجاد یک پایگاه داده غنی و استاندارد از شاعران، دیوان‌ها، قالب‌های شعری و اوزان عروضی.
- ارائه APIهای تمیز برای تعامل فرانت‌اند و سایر سرویس‌ها.
- پیاده‌سازی سیستم احراز هویت امن و پروفایل کاربری.
- چشم‌انداز آینده: پیاده‌سازی پلتفرم رقابت آنلاین شعر (بازی مشاعره تعاملی با تایمر و قوانین اوزان و حروف قافیه).
