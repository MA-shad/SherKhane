# شعرخونه (SherKhaneh Vibe Coding)

پلتفرم وب فارسی برای تجربهٔ زنده، تعاملی، روزمره و هوشمند ادبیات کهن فارسی.

---

## ۱. ساختار کلان پروژه

```text
SherKhane-vibe-coding/
├── backend/                  # بک‌اند ماژولار جنگو و جنگو رست فریم‌ورک
│   ├── accounts/             # مدیریت کاربران، سطوح تسلط، نشان‌ها و احراز هویت با JWT
│   ├── core/                 # نرمال‌ساز متن و املای فارسی، پاکسازی اعراب و تطبیق حروف
│   ├── poetry/               # گنجینه اشعار، شاعران، اوزان عروضی، قالب‌ها و کاتالوگ دیوان
│   ├── library/              # دفترچه شخصی، نشانه‌گذاری و یادداشت‌های کاربر
│   ├── memorization/         # استودیو حفظ شعر با متد لایتنر و تکرار با فاصله (SM-2)
│   ├── mushaereh/            # تالار مشاعره زنده با داوری مقتدرانه سرور و ربات سخن‌سنج
│   ├── games/                # بازی‌های ادبی (بیت‌چین، حدس شاعر، تکمیل مصراع، واژه‌نامه)
│   ├── daily_content/        # فال حافظ همراه با تعبیر معنوی، بیت روز و ضرب‌المثل روز
│   ├── tests/                # مجموعه ۱۶ آزمون خودکار واحد و یکپارچگی (۱۰۰٪ قبولی)
│   ├── manage.py
│   └── requirements.txt
├── frontend/                 # وب‌اپلیکیشن واکنش‌گرا و راست‌چین با پالت رنگی زرین
│   ├── index.html            # واسط کاربری یکپارچه و مدرن
│   ├── css/style.css         # سیستم طراحی فاخر و راست‌چین
│   └── js/                   # ماژول‌های ارتباط با سرور و منطق تعاملی
├── docs/                     # اسناد ۲۰گانه معماری و ممیزی سیستم (Blueprint)
├── run_backend.bat           # اسکریپت اجرای تک‌کلیکی سرور جنگو
└── run_frontend.bat          # اسکریپت باز کردن سریع فرانت‌اند در مرورگر
```

---

## ۲. راهنمای اجرای سریع پروژه

### اجرای بک‌اند:
روی فایل زیر دابل‌کلیک کنید یا دستور زیر را در خط فرمان اجرا نمایید:
```bash
run_backend.bat
```
سرور بر روی آدرس زیر اجرا می‌شود:
```text
http://127.0.0.1:8000/
```

### اجرای فرانت‌اند:
روی فایل زیر دابل‌کلیک کنید:
```bash
run_frontend.bat
```
همچنین می‌توانید فایل `frontend/index.html` را مستقیماً در هر مرورگری باز کنید. فرانت‌اند به گونه‌ای طراحی شده است که چه سرور بک‌اند روشن باشد و چه خاموش، به صورت هوشمند از مخزن داده‌های اصیل داخلی استفاده کرده و فوراً به شکل کامل کار می‌کند.

---

## ۳. اجرای آزمون‌های خودکار

برای اجرای کلیه آزمون‌های خودکار سیستم:
```bash
python backend/manage.py test tests
```
کلیه آزمون‌ها با موفقیت ۱۰۰٪ پاس می‌شوند.
