# معماری کلان سیستم شعرخونه (System Architecture)

این سند، معماری فنی، مرزهای دامنه و نحوهٔ جریان داده و درخواست‌ها را در سامانهٔ شعرخونه تبیین می‌کند.

---

## ۱. الگوی معماری: یکپارچه ماژولار (Modular Monolith)

رویکرد انتخابی برای شعرخونه، معماری یکپارچه ماژولار است. در این الگو:
- هسته برنامه واحد و توسعه‌پذیر در قالب یک پروژه جنگو مدیریت می‌شود.
- مرزهای دامنه‌ای به وضوح در قالب اپلیکیشن‌های مستقل و تخصصی تفکیک شده‌اند.
- منطق کسب‌وکار در لایه سرویس متمرکز است و ویوها صرفاً هدایت‌کننده درخواست و پاسخ هستند.
- از پیچیدگی‌های زودرس مایکروسرویس‌ها، سربار شبکه و هزینه‌های گزاف استقرار اجتناب می‌گردد.

```mermaid
graph TD
    Client[کلاینت وب / مرورگر دسکتاپ و موبایل] -->|HTTPS / JSON REST API| Gateway[سرور وب و وارون‌نما NGINX]
    Gateway -->|WSGI / ASGI| DjangoCore[بک‌اند جنگو Modular Monolith]
    
    subgraph DjangoCore [مرزهای ماژولار بک‌اند جنگو]
        AccountsApp[ماژول حساب‌ها و کاربران]
        PoetryApp[ماژول شعر و کاتالوگ دیوان]
        LibraryApp[ماژول دفترچه و علاقه‌مندی‌ها]
        MemoApp[ماژول حفظ و تکرار با فاصله]
        GamesApp[ماژول بازی‌ها و داوری مشاعره]
        DailyApp[ماژول محتوای روزانه و فال حافظ]
    end
    
    DjangoCore -->|اتصال پایدار| Postgres[(پایگاه داده پستگرس ۱۶)]
```

## ۲. جریان پردازش درخواست‌ها (Request Lifecycle)

```mermaid
sequenceDiagram
    autonumber
    actor کاربر as کاربر وب
    participant فرانت as کلاینت فرانت‌اند
    participant ویو as لایه نما / ViewSet
    participant سرویس as لایه منطق تجاری / Service
    participant مدل as لایه مدل و پایگاه داده
    
    کاربر->>فرانت: انتخاب گزینه یا ارسال فرم
    فرانت->>ویو: ارسال درخواست همراه با توکن احراز هویت
    ویو->>ویو: اعتبارسنجی ساختار با سریالایزر
    ویو->>سرویس: فراخوانی متد تجاری
    سرویس->>سرویس: اعمال قوانین، محاسبات و اعتبارسنجی ضدتقلب
    سرویس->>مدل: ثبت، به‌روزرسانی یا جست‌وجو در پایگاه داده
    مدل-->>سرویس: بازگشت رکوردها
    سرویس-->>ویو: نتیجه عملیات تجاری
    ویو-->>فرانت: پاسخ استاندارد با فرمت جیسون
    فرانت-->>کاربر: نمایش به‌روزرسانی رابط کاربری
```

## ۳. امنیت، ثبات و انعطاف‌پذیری
1. **احراز هویت:** بر پایه استاندارد توکن حامل با دوره انقضای مشخص و اعتبارسنجی خودکار.
2. **پایداری داده‌ها:** پایگاه داده پستگرس به عنوان منبع واحد حقیقت داده‌های ادبی و کاربری.
3. **لایه خدمات مستقل:** جداسازی منطق بازی و حفظ شعر از لایه پایگاه داده به منظور تسهیل تست‌های خودکار.
